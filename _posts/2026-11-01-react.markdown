React를 13페이지로 정리했습니다. 단원마다 연습 예제와 함께, 동아리 프로젝트 잔디로그 웹 화면에서 실제로 쓴 코드를 붙였습니다.<!-- outline-end -->

## 배운 내용

- `setCount(count + 1)`을 두 번 불러도 1만 오릅니다. 이전 값을 기준으로 바꿀 때는 `setCount(c => c + 1)`처럼 함수를 넘깁니다.
- 목록을 그릴 때 `key`에는 순번 대신 항목마다 바뀌지 않는 값을 줍니다.
- 입력칸은 `value`와 `onChange`를 짝으로 두어 state와 화면 값을 같게 만듭니다.
- 한글은 조합 중에도 Enter 키 이벤트가 옵니다. 잔디로그 태그 입력칸에서는 `isComposing`일 때 태그를 확정하지 않게 했습니다.
- 잔디로그에서는 서버 데이터를 `useQuery`로 불러왔고, `useEffect`는 키보드 단축키처럼 브라우저 이벤트를 붙이고 떼는 데 썼습니다.
- 로그인 정보처럼 거의 모든 화면이 쓰는 값은 props로 계속 넘기지 않고 Context로 나눠 줍니다.
- 로그인하지 않은 사람은 가드 컴포넌트가 `<Navigate>`로 로그인 화면에 보내고, 통과하면 `<Outlet>`으로 자식 화면을 그립니다.
